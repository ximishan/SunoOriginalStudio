# Excel 模板目录

当前正式模板：

- `SunoOriginalStudio批量原创模板_v0.5.8.xlsx`

用途：给 SunoOriginalStudio v0.5.8 的“Excel 批量原创”页面直接导入。

第一张工作表必须是批量数据表；程序只读取第一张工作表。标准表头：

```text
歌名 | 歌词 | 风格 | 排除风格 | 模型 | 人声 | Weirdness | 风格影响 | 账号 | 提交间隔秒 | 启用
```

最少填写“歌名 + 歌词”即可，其他列可使用默认值。模板中的第二张工作表“填写说明”不会作为歌曲数据读取。

提交间隔默认 20 秒，允许 5-300 秒；Excel 单行填写的间隔优先于软件全局值。该间隔只用于控制请求频率。

详细规则、队列状态、暂停/恢复、异常退出和账号行为见仓库根目录 `BATCH_EXCEL_V0.5.8.md`。

维护规则：每次 Excel 字段结构发生变化，都必须同步更新模板文件、`BATCH_EXCEL_V0.5.8.md`、README 和 `PROJECT_STATUS_AND_AVR_FEATURES.md`，并在新正式版本中使用新的模板文件名，避免旧模板和新代码混用。
