# SunoOriginalStudio

独立的 Suno 原创歌曲桌面工具实验项目。

## 当前快照

当前主分支先保存 `v0.1.1` 可运行源码，来源于 `MusicVMAuto` 中的 `suno-original-demo-v0.1.1-snapshot` 分支，作为后续修改前的基线。

当前功能：

- 3 个独立、持久化的 Suno 账号 Session
- 自定义歌名、完整歌词、风格提示词
- 原创歌曲提交
- 任务状态刷新
- Suno 要求人机验证时打开对应账号窗口，并等待用户完成官方验证后继续流程

> 人机验证只使用 Suno 官方验证流程，不做验证码破解、识别或绕过。
